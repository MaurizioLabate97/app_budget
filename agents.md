# App Budget — progetto locale

App personale React + Vite + Capacitor. I dati vengono conservati sul dispositivo tramite SQLite nelle build native; la preview web usa localStorage esclusivamente per lo sviluppo.

## Comandi
- `npm install`
- `npm run dev`
- `npm run build`
- `npm run cap:sync`
- `npm run ios` (richiede macOS e Xcode)
- `npm run android`

Non aggiungere autenticazione, backend o sincronizzazione cloud senza una richiesta esplicita.
